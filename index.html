Privacy Policy

Adaptive Cycling Coach
Last updated: 25 August 2026

1. Purpose of the application

Adaptive Cycling Coach is a private, non-commercial application used by its owner to analyse personal training, recovery and related physiological data and to support individual cycling training planning.

2. Data obtained from WHOOP

With the user's explicit authorization, the application may access WHOOP data made available through the WHOOP API, including recovery, cycle, sleep, workout, profile and body-measurement data. The application only accesses scopes that the user has authorized.

3. How the data is used

WHOOP data is used solely to provide personal training analysis, recovery assessment, training-load interpretation and adaptive training recommendations for the authorized user. The data is not used for advertising, marketing, profiling of third parties, or any unrelated commercial purpose.

4. Storage and security

Application data is stored in the owner's private application environment. OAuth access and refresh tokens are not published in source-code repositories. Where supported by the application, authentication tokens are encrypted at rest. Reasonable technical measures are used to limit access to the authorized user and the application components required to provide the service.

5. Sharing and sale of data

Personal data obtained from WHOOP is not sold, rented, or disclosed to advertisers or data brokers. Data may be processed by technical service providers only where necessary to operate the application or provide explicitly requested analytical functionality, subject to their applicable privacy and security terms.

6. Data retention and deletion

Data is retained only for as long as it is useful for the personal training-analysis purpose of the application. The user may revoke WHOOP access at any time through WHOOP's account or connected-app settings. Stored application data and OAuth credentials can also be deleted from the application environment on request.

7. User control

The user controls whether the application is connected to WHOOP and which permissions are granted. Revoking authorization prevents future API access. Historical copies held by the application can be deleted separately.

8. Cookies and tracking

This privacy-policy page does not use analytics, advertising trackers, or cookies set by Adaptive Cycling Coach. GitHub Pages, as the hosting provider for this page, may process technical request data under GitHub's own terms and privacy policy.

9. Changes to this policy

This policy may be updated if the application's data flows or integrations change materially. The current version and its update date will remain available at this URL.

10. Contact

For privacy questions or requests concerning Adaptive Cycling Coach, use the contact email address provided in the corresponding WHOOP Developer application registration.
